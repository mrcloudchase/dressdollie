# Dress Dollie

A kid-friendly dress-up game starring fashion dolls. Open `index.html` in any browser — no install, no internet, no tracking.

- 6 dolls (different skin tones, eyes, hairstyles) you can customise
- 7 hairstyles + hair colours, 6 dresses, 5 tops, 5 bottoms, 5 shoes — all recolourable
- 9 extras (crown, wings, sunglasses, purse, wand…) and 6 magical places
- 🎲 Surprise me, 💃 Twirl, 📸 Save a picture (PNG), 🔄 Start over
- Touch-friendly; works on phones, tablets and desktop. Your doll is remembered in the browser.
